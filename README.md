## ⚙️ How to Run Locally

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install pandas numpy matplotlib seaborn jupyterlab
jupyter lab
```

Open notebooks and run cells top-to-bottom.
